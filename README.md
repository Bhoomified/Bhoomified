## 🧠 what i actually build

I don't do generic CRUD apps for fun — I like systems that **connect, reason, and predict**: knowledge graphs, RAG pipelines, forecasting models, and AI copilots that solve a real problem end to end (model → API → interface).

### 🧬 Memora
**AI-powered Digital Identity & Knowledge Graph Engine**
> Built for the Memoryverse Hackathon

Connects `growth → achievements → skills → experiences → knowledge` using a causal knowledge graph (`LED_TO`, `BUILT_ON`, `APPLIED_IN`), OCR ingestion, and a RAG chatbot with citations.

`FastAPI` `ChromaDB` `NetworkX` `Groq (Llama 3.1)` `D3.js` `Docker` `Railway`

**[🔴 Live Demo →](https://memora-production-2406.up.railway.app)**

### 💸 NeetiAi
**AI Personal Finance Assistant — built for India**

Expense categorization (TF-IDF + XGBoost), spend forecasting (Random Forest), a budget optimizer (SciPy SLSQP), a fine-tuned DistilBERT financial chatbot, and a risk-profiled investment module with live mutual-fund NAV data.

`Next.js` `FastAPI` `SQLModel` `DistilBERT` `spaCy` `XGBoost`

*"The intelligence behind your finances."*
